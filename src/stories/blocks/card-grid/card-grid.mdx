# Card Grid

Card grid block that builds a grid of Card organisms from an ACF `items` repeater. When the repeater is absent or empty the block falls back to `block.renderedHtml`, preserving the WordPress-rendered inner `acf/card` blocks.

## Usage

```tsx
import { CardGridBlock } from '@/stories/blocks/card-grid/CardGridBlock';

<CardGridBlock block={block} />
```

## ACF Fields

| Field | Type | Description |
|---|---|---|
| `type` | select | Layout strategy: `grid`, `row`, `group`, or `deck` |
| `column_count` | number | Number of columns: 2–6 |
| `title` | text | Optional heading above the grid |
| `placecard` | true_false | Adds `.has-placecard` and invisible filler spans |
| `single_row` | true_false | Lock to a single horizontal row |
| `mobile_columns` | true_false | Preserve multi-column layout on mobile |
| `vertical_offset` | select | Stagger cards vertically: `left` or `right` |
| `numbered_cards` | true_false | Add `card-count` class to the inner grid |
| `card_grid_width` | group | Block-level CSS width |
| `card_grid_margin` | group | Block-level margin |
| `items` | repeater | Headless card data; each row mirrors a subset of `CardBlockData` fields |

Each `items` row supports: `card_title`, `card_subtitle`, `card_text`, `card_header`, `card_footer`, `card_label`, `image`, `image_position`, `image_overlay`, `card_link`, `card_linked`, `show_button`, `button`, `card_background`, `card_border`, `no_border`, `text_alignment`, `text_color`, `card_element`.
