# Hero Unit

Full-width hero block. Wraps content in a `<div class="block-hero-unit">` with optional palette-based or custom background and text color classes.

## Usage

```tsx
import { HeroUnitBlock } from '@/stories/blocks/hero-unit/HeroUnitBlock';

<HeroUnitBlock block={block} />
```

## ACF Fields

| Field | Type | Description |
|---|---|---|
| `section_variant` | group | Color variant settings |
| `section_variant.type` | select | `palette` or `custom` |
| `section_variant.color` | select | Bootstrap palette name (e.g. `primary`, `light`) when type is `palette` |
| `section_bg_color` | color_picker | Custom hex background color when type is `custom` |
| `section_text_color` | color_picker | Custom hex text color when type is `custom` |

## Class / Style Generation

- **Palette**: adds `bg-{color}` and/or `text-{color}` class.
- **Custom**: adds `backgroundColor` and/or `color` inline style.
